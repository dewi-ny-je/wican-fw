Datalogger

Log selected PID values at a chosen frequency. Data is buffered, then uploaded to InfluxDB v1 over HTTPS when Wi-Fi is up, or written to the SD card (WiCAN Pro) when offline.

Values are sampled from the AutoPID engine, so set the protocol to AutoPID and configure your PIDs there first.
